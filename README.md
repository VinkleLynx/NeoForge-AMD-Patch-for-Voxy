
Information
===

This is (Neo)forge port of [AMD Patch For Voxy](https://github.com/1MarcosDev/AMD-Patch-for-Voxy) for Minecraft 1.20.1 / 1.21.1, using for fix render issue on `AMD RX 400 / 500` Series for [Voxy](https://github.com/MCRcortex/voxy)

Tested on:
===

| Repositories | Version | Minecraft Version |
|-|-|-|
| [j-shelfwood / voxy-neoforge](https://github.com/j-shelfwood/voxy-neoforge) |  0.2.9, build from source | 1.21.1 |
| [meansabine / neo-voxy](https://github.com/meansabine/neo-voxy) | 0.2.0, build from source | 1.21.1 |
| [NHblock-Johnsnow / neo-voxy](https://github.com/NHblock-Johnsnow/neo-voxy) | 0.3.3, github actions | 1.20.1 / 1.21.1 |
