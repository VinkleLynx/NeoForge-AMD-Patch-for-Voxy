
Information
===

This mod is a Neoforge port of [AMD Patch For Voxy](https://github.com/1MarcosDev/AMD-Patch-for-Voxy) for Minecraft 1.21.1.

This mod is using for fix render issuse on `AMD RX 400 / 500` Series for [Voxy](https://github.com/MCRcortex/voxy)

Tested on:
===

| Repositories | Version |
|-|-|
| [j-shelfwood / voxy-neoforge](https://github.com/j-shelfwood/voxy-neoforge) | build from source, 0.2.9 |
| [meansabine / neo-voxy](https://github.com/meansabine/neo-voxy) | build from source, 0.2.0 |
